# Sunday Reset

Plan your week around your calendar. Import a Google Calendar export, add the week's tasks, and they're placed in your free time. Drag them around, then export them as `.ics` files for Google Calendar.

Runs in your browser on a tablet, laptop or desktop (not phones).

## On an iPad

- Use it in Safari, or add it to the Home Screen (Share → Add to Home Screen). The Home Screen copy keeps its own data, and Safari can clear a website's saved data after a week without a visit, so pick one and stay with it.
- The Google Calendar app can't import or export files. Both happen on the Google Calendar website, which the app's help links to.
- Exported `.ics` files go to Files → Downloads. The Share button can save them elsewhere.

```bash
npm install
npm run dev
```
